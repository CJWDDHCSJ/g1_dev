## 2. 节点与话题关系

| 节点 | 订阅 | 发布 |
|---|---|---|
| `/g1_asr_bridge` | `/audio_msg` | `/g1/asr_text` |
| `/g1_robot_state_provider` | `/lowstate`、`/sportmodestate`、`/arm/action/state`、`/dog_odom`、`/lf/bmsstate` | `/g1/robot_state` |
| `/g1_voice_router` | `/g1/asr_text`、`/g1/robot_state`、`/g1/action_result` | `/g1/tts`、`/g1/action_request` |
| `/g1_tts_node` | `/g1/tts` | （音频设备） |
| `/g1_action_executor` | `/g1/action_request`、`/arm/action/state`、`/sportmodestate`、`/lowstate` | `/g1/action_result` |

实测约束（生产 Domain 0）：`/g1/action_request` 发布者恒为 1（Router），订阅者恒为 1（Executor）；`/g1/action_result` 发布者恒为 1（Executor），订阅者恒为 1（Router）。

## 3. 进程与生命周期

- 5 个 user service 由 `g1-voice-stack.target` 组合，`PartOf` 关联，`Restart=always`，`KillSignal=SIGINT`，`TimeoutStopSec=15`。
- Router 停机实测：空闲 0.29s、HTTP 请求中 0.79s（curl 回调中止）、动作等待中 0.29s。
- 整机重启后 45s 内全部服务自动恢复（实测 06:03:48 启动）。
- 日志：`~/g1_logs_systemd/*.log` + 按日轮转；磁盘检查与轮转由独立 service/timer 执行。

## 4. 数据流分层

1. **感知层**：ASR 文本、BMS/IMU/关节/动作/里程计原始话题。
2. **适配层**：ASR Bridge、RobotStateProvider（把原始话题转成聚合 JSON，含有效性判定）。
3. **业务层**：Voice Router（归一化 → 意图 → 分流 → 回复）。
4. **执行层**：TTS 播报、Action Executor 动作。
5. **外部服务**：Ollama 通用问答。

## 5. 隔离验证架构

生产 Domain 0 之外，使用 `ROS_DOMAIN_ID=77` 启动同版本 Router，配合三个 Mock（Ollama HTTP、Action Executor、RobotStateProvider）验证业务分支，不触发真实动作、不影响生产节点。
