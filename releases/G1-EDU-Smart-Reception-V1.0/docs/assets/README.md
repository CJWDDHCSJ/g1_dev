# 素材目录（待补充实拍）

本目录用于放置**本项目自己的**实机照片、终端截图与演示视频。当前为空：归档时没有可用的实拍素材，为避免用他人素材冒充，未放任何占位图片或生成图。

README 的「实机展示」章节已留好引用位置，放入文件后替换对应占位即可。

## 1. 命名与内容约定

| 文件名 | 内容 | 拍摄/制作要求 |
|---|---|---|
| `g1_edu_full.jpg` | G1-EDU 整机 | 正面或侧前视角，能看清机型与实验室环境 |
| `g1_wave.jpg` | 真实挥手瞬间 | 对应 P0-20.1 的 `success:wave:26`，最好能看出是同一场景 |
| `reception_scene.jpg` | 接待现场（机器人 + 参观者） | **必须**取得出镜人员肖像授权，或做模糊处理 |
| `terminal_nodes.png` | `ros2 node list` + 五个 service 状态 | 截图前遮挡内网 IP、主机名、用户名 |
| `terminal_topics.png` | `ros2 topic info /g1/robot_state` | 同上 |
| `terminal_log.png` | 一行 `event=COMPLETED total_ms=...` | 可保留时间戳，遮挡路径中的用户名 |
| `demo.mp4` | 完整接待演示 | 30–90 秒，至少含 1 次问答 + 1 次挥手 |

## 2. 在 README 中引用

```markdown
![G1-EDU 整机](docs/assets/g1_edu_full.jpg)
![真实挥手](docs/assets/g1_wave.jpg)
```

视频建议用相对路径 + 说明文字，或改为外部链接（B 站/YouTube），避免仓库体积膨胀：

```markdown
演示视频：[`docs/assets/demo.mp4`](docs/assets/demo.mp4)（或外部链接）
```

## 3. 禁止放入的内容

- 含内网 IP、SSH 端口、主机名、token 的截图；
- 未经同意的他人肖像、姓名、工牌信息；
- 真实语音原始录音（`*.wav`）与完整语音转写文本；
- 实验室未公开的内部数据（人员、经费、未发表成果）；
- 他人拍摄的 G1 机器人照片（不能代表本项目）。

## 4. 体积与格式

| 类型 | 建议 |
|---|---|
| 图片 | 宽度 ≤ 1600 px，单张 ≤ 500 KB，优先 JPG/PNG |
| 视频 | ≤ 20 MB，优先 H.264 MP4；更大请放外部平台并只留链接 |

## 5. 为什么现在留空

项目文档里所有“已验证”的结论都来自日志与阶段报告；照片只是**展示**，不能作为验收证据。因此在没有真实素材时，宁可留空，也不使用示意图伪装现场记录。
