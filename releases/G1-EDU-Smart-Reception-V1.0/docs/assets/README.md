## 建议补充

| 文件名建议 | 内容 | 要求 |
|---|---|---|
| `g1_edu_full.jpg` | G1-EDU 整机 | 正面/侧面，能看清机型 |
| `g1_wave.jpg` | 真实挥手瞬间 | 与 P0-20.1 验收对应 |

| `terminal_topics.png` | `ros2 topic info /g1/robot_state` | 同上 |
| `demo.mp4` | 完整接待演示 | 建议 1–3 分钟，含问答+挥手 |

## 使用方式

README 中已预留对应引用位置（`docs/assets/...`）。放入文件后取消 README 中相应注释即可。

## 注意

- 不要放入含内网 IP、主机名、SSH 信息的截图；
- 不要放入未经同意的他人肖像或对话录音；
- 图片建议宽度 ≤1600px、单张 ≤500KB，避免 README 加载过慢。
