5. 历史备份与回滚路径

### 已知限制

1. 仅支持 6 个真机验证过的动作；其余动作未纳入白名单。
2. ASR 对短词/专有名词仍有误识（已对 2 类做归一化，其余保留原文）。
3. 动作结果无请求 ID，同名动作不支持并发。
4. 未实现导航、人脸识别、视觉识别。
5. 外部模型依赖局域网笔记本，断网时仅本地能力可用。

### 后续规划（不属 V1.0）

- 动作结果协议增加请求 ID
- 扩充 ASR 别名词典与实验室知识库
- 增加视觉/导航能力（需另行真机验证）
