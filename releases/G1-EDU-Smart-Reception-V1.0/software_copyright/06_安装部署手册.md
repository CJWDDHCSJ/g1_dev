# 06 安装部署手册

## 1. 硬件与系统

| 项目 | 要求 |
|---|---|
| 机器人 | Unitree G1-EDU（Jetson Orin NX，ARM64） |
| 系统 | Ubuntu 22.04.5 LTS，JetPack 6.2.3，CUDA 12.6，TensorRT 10.3 |
| ROS | ROS 2 Humble + CycloneDDS（`rmw_cyclonedds_cpp`） |
| 模型服务器 | Ubuntu 笔记本（RTX 4070 Laptop 8GB），Ollama + `qwen3-vl:4b-instruct` |
| 网络 | G1 `192.168.123.164` ↔ 笔记本 `192.168.123.99`（eth0 直连） |

## 2. 目录结构

```text
~/unitree_ros2/example/
├── g1_voice_router/        # 主业务包（源码/测试/配置）
├── g1_asr_bridge/          # ASR JSON 桥
├── src/src/g1/audio_client/g1_tts_node.cpp   # TTS 节点
├── config/tts_config.json
└── install/ g1_voice_router（symlink-install）
~/lidar_ws/src/g1_action_executor/            # 动作执行器
~/g1_systemd/scripts/                         # systemd 启动脚本
~/g1_logs_systemd/                            # 运行日志
```

## 3. 部署步骤

```bash
# 1) 同步源码到 G1（以实际开发机为准）
scp -r g1_voice_router unitree@192.168.123.164:~/unitree_ros2/example/

# 2) 编译
ssh unitree@192.168.123.164
source ~/unitree_ros2/setup.sh
cd ~/unitree_ros2/example
colcon build --packages-select g1_voice_router --symlink-install

# 3) 测试
colcon test --packages-select g1_voice_router
colcon test-result --verbose     # 期望 7 tests, 0 errors, 0 failures

# 4) 启动整套服务
systemctl --user start g1-voice-stack.target

# 5) 校验
ros2 topic info /g1/asr_text     # 1/1
ros2 topic echo /g1/robot_state --once
```

## 4. 依赖清单

| 依赖 | 版本/说明 |
|---|---|
| rclcpp / std_msgs | ROS 2 Humble 自带 |
| unitree_hg / unitree_go 消息 | `~/unitree_ros2/cyclonedds_ws` |
| unitree_sdk2 / AudioClient | G1 官方 SDK（TTS 使用） |
| nlohmann/json | 工作区已有头文件 |
| libcurl | 系统库（HTTP 调用 Ollama） |
| pthread | 系统库 |
| Python 3 | 仅 Mock/验证脚本使用，非运行依赖 |

## 5. 部署校验清单

1. `systemctl --user is-active g1-voice-stack.target` → active
2. 5 个 service 的 MainPID 均非 0 且互不相同
3. `ps | grep g1_voice_router/voice_router` 只有 1 个进程
4. `/g1/action_request` 发布者只有 Router；`/g1/action_result` 发布者只有 Executor
5. `curl http://192.168.123.99:11434/api/tags` 返回模型列表
6. Router 日志出现 `KnowledgeBase loaded` 与 `Ollama URL` 两行

## 6. 升级与回滚

升级：备份旧二进制 → 覆盖 → 只重启 `g1-voice-router.service` → 校验 `/proc/PID/exe` 哈希。
回滚：停止单服务 → 还原备份二进制 → 校验哈希 → 启动单服务。**禁止重启 target**。
