## 3. V1.0 功能范围（与源码一致）

已实现：

1. 真实麦克风语音输入（Unitree 原生 ASR）→ `/audio_msg` → `g1_asr_bridge` → `/g1/asr_text`。
2. ASR 专有名词归一化（`AsrTextNormalizer`，有限词典，2 条规则）。
3. 意图识别（13 类：GREETING / LAB_INTRO / ROBOT_INTRO / DEMO_ACTION / ROBOT_STATUS / GOODBYE / GENERAL_QA 等）。
4. 交互任务管理（`InteractionManager`：过滤、去重窗口、有界 FIFO、统一单 worker 回复调度）。
5. 事实风险保护（`FactRiskGuard`：PRICE / REALTIME_STATUS / LAB_FACT / NORMAL）。
6. 本地知识库（`KnowledgeBase` + `lab_knowledge.json`：FAQ 21、研究方向 3、项目 1、设备 1、来源 15）。
7. 机器人状态聚合（`RobotStateProvider` + `RobotStateEvaluator`：电池/关节/IMU/动作/里程计，VALID/STALE/UNAVAILABLE/INVALID 四态）。
8. 动作白名单与语音触发（`ActionCommandMapper`：wave 26 / wave_low 25 / hands_up 15 / clap 17 / heart 20 / victory 30；ID 33 永久禁用），经 `g1_action_executor` 执行并回传 `/g1/action_result`。
9. TTS 播报（`g1_tts_node`，分句 + 播放等待）。
10. 外部大模型问答（Ubuntu 笔记本 Ollama `qwen3-vl:4b-instruct`，`http://192.168.123.99:11434/api/chat`）。
11. systemd 生命周期管理、开机自恢复、日志轮转、磁盘检查。

未实现（明确不在 V1.0 范围）：自主导航、人脸识别、视觉识别、语义地图、深度相机依赖、云端多轮管理后台。
