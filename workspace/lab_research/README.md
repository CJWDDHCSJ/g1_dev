## 四、最重要的三条使用规则

1. **名称要用官方全称**：正式场合说“脑机交互智能研究中心”“人形机器人具身智能感知与自主学习重庆市重点实验室”；“实验室”是口语称呼，不是官方名称。
2. **没有公开依据就不说**：设备型号、数量、团队规模、场地面积、中心/实验室成果清单均未公开；被问到就用 FAQ 的兜底话术。
3. **不混归属**：教师个人论文/专利、学生竞赛、刘宏教授在北京大学的工作、本项目使用的 G1，都不能说成“实验室成果/实验室设备”。
