## 3. G1 真机语音测试

### 3.1 P0-16（历史，已验证）

真实麦克风 → ASR → Router → 知识库/Ollama → TTS → 扬声器全链路通过；GREETING 触发挥手 4/4 成功。

### 3.2 P0-20.1（已验证）

- 非动作回归 5 项：自我介绍/实验室介绍/电量/动作状态/运行状态均正确，动作请求 0。
- `挥个手`：`request_id=7`，wave/26，`success:wave:26`，TTS"好的，挥手动作完成了。"，真实挥手完成，请求 1 次。

| # | 目标语句 | ASR 实际文本 | 意图 | 路径 | TTS 字节 | 结果 |

动作请求计数：0；无重复播报；无 DUPLICATE/FILTERED 记录。

**已知真机缺陷（用户反馈"部分对话需说第二遍"的根因）**：ASR 对"脑机接口"存在多种误识变体（已观测 `脑急接口`、`脑筋接口`）。V1.0 已覆盖前两种，第三种及以后需继续按证据扩充词典，或改用更完整的说法。
