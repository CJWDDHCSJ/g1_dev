## 5. ASR001 专项复核（P0-21 补充，2026-11-03）

- 静态校验：规则在源码、运行二进制内均存在；
- 真机单次输入：ASR 输出 `手机接口是什么？`（第三种变体），**未触发 ASR001 分支**；
- 结论：**该别名规则目前只有单元测试证据，真机未验证到**；
- 未新增“手机接口”别名：该词是合法提问，映射会破坏正常语义。

## 6. 整机重启恢复（P0-18.3，2026-11-03 06:03）

重启后 5 个 user service 在 45s 内自动恢复，`NRestarts=0`，Router 加载的仍是 install 指向的新版本。
