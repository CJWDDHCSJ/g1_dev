# 05 数据与配置说明

本系统不使用数据库（无 SQL/NoSQL 依赖），全部数据以 JSON 配置文件与运行时消息形式存在。

## 1. 知识库配置 `config/lab_knowledge.json`

| 字段 | 类型 | 说明 | 当前规模 |
|---|---|---|---:|
| `faq` | 数组 | 常见问题与答案，含 id、question、answer、keywords、sources | 21 |
| `research_directions` | 数组 | 研究方向 | 3 |
| `projects` | 数组 | 科研项目 | 1 |
| `equipment` | 数组 | 设备信息 | 1 |
| `categories` | 数组 | 实验室分类 | 5 |
| `labs` | 数组 | 实验室条目 | 3 |
| `sources` | 数组 | 事实来源（学校/学院官网、科研公示、教师公开资料等） | 15 |

设计要点：
1. 启动时一次性加载常驻内存，运行期不写回。
2. 每条事实保留来源 ID，回答时可追溯。
3. 未收录内容统一返回"暂无经过核实的公开资料"，不做推测。
4. 同一问题命中多条且分数相同且无法区分时返回安全兜底。

## 2. 提示词配置（ROS 参数）

`system_prompt`（Router 参数，可运行时覆盖）：约束模型不编造价格、人员数量、科研成果、项目进展、设备型号规格、机器人实时状态；不确定时必须说明。

## 3. TTS 配置 `config/tts_config.json`

| 字段 | 当前值 | 说明 |
|---|---:|---|
| `speaker_id` | 0 | 发音人 |
| `volume` | 80 | 音量 |
| `pause_ms` | 1500 | 句间停顿 |

## 4. Router 关键 ROS 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `ollama_url` | `http://192.168.123.99:11434/api/chat` | 外部模型地址 |
| `model_name` | `qwen3-vl:4b-instruct` | 模型名 |
| `request_timeout_seconds` | 60 | HTTP 整体超时 |
| `action_timeout_seconds` | 45 | 动作结果等待超时（> 执行器最坏 38s） |
| `knowledge_file` | 空（用 ament share 路径） | 知识库路径覆盖 |

## 5. 运行时状态消息 `/g1/robot_state`（schema_version = 1）

```json
{
  "schema_version": 1,
  "battery": {"status": "VALID", "soc_percent": 93, "soh_percent": 94,
              "voltage_mv": 50173, "received_age_ms": 120,
              "quality_reason": "", "source_topic": "/lf/bmsstate"},
  "imu":     {"status": "VALID", "data_available": true, "received_age_ms": 90,
              "source_topic": "/lowstate"},
  "runtime": {"status": "VALID", "lowstate_available": true,
              "sportmode_available": true, "received_age_ms": 80},
  "action":  {"status": "VALID", "action_id": 0, "action_name": "",
              "is_executing": false, "received_age_ms": 70,
              "source_topic": "/arm/action/state"}
}
```

`status` 四态：`VALID`（有效且新鲜）、`STALE`（有数据但过期）、`UNAVAILABLE`（无数据源）、`INVALID`（格式或数值异常）。

## 6. 日志字段约定

| 事件 | 关键字段 |
|---|---|
| 请求入队 | `request_id`、`queue_depth`、`text_len` |
| 归一化 | `rule`、`raw_len`、`raw_digest`、`normalized` |
| 处理 | `intent`、`text_len` |
| 风险 | `risk`、`blocked`、`use_local`、`reason` |
| 动作 | `ACTION_SENT action/id`、`ACTION_FINISHED outcome` |
| 完成 | `COMPLETED total_ms` / `FAILED reason` |

日志不打印完整用户语音，仅长度、意图与必要的归一化结果。
