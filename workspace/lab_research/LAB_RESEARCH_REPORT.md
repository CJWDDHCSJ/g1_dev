## 一、任务与边界

### 1.1 任务目标

为 G1-EDU 校园接待/讲解系统建立一套**真实、可追溯、可核验**的实验室知识底稿，后续再用于机器人讲解和知识库开发。

### 1.2 本轮范围

- 调研学校、学院、两个实验室相关方向的公开信息。
- 建立来源清单、事实核验表、冲突清单、待确认清单。
- 产出三层级讲解词和访客问答草稿。
- 不修改机器人代码，不生成/覆盖知识库 JSON，不接入运行链路。

### 1.3 本轮明确不做

- 不修改 `g1_voice_router` 的 C++ 代码。
- 不覆盖 `lab_knowledge.json`。
- 不接入机器人运行链路。
- 不采集私人联系方式、学生名单、内部网络地址、内部账号、未公开项目细节。
- 不读取与任务无关的私人文件。

## 二、调研能力与工具

### 2.1 能力检查结论

| 能力 | 是否具备 | 说明 |
|---|---|---|
| 网络搜索 | 具备 | 使用内置 WebSearch，无需新增 MCP |
| 网页正文提取 | 部分具备 | WebFetch 可用，但重庆理工大学站点被 WAF 拦截 |
| 浏览器访问 | 具备但受限 | browser-use MCP 可打开页面，但官方站点返回 JS 挑战，页面空白 |
| PDF 读取 | 具备 | 下载官方 PDF 后用 `pdftotext` 提取，成功核验重点实验室名单 |
| DOCX/PPTX 读取 | 具备 | 本轮未遇到需要读取的 DOCX/PPTX 材料 |

**结论**：现有工具已能满足调研需要，**没有安装新的 MCP，没有修改任何全局或项目 MCP 配置，没有使用 API Key**。

### 2.2 实际使用的工具

| 工具 | 用途 | 使用方式 | 备注 |
|---|---|---|---|
| WebSearch（内置） | 主检索工具 | 中文关键词检索、站点定向检索 | 主要发现渠道 |
| WebFetch（内置） | 打开可访问的原文 | 读取华龙网、科学网、CCBR、宇树官网 | 部分站点可直读 |
| browser-use MCP | 浏览器渲染与截图 | `navigate_page`、`take_screenshot`、`evaluate_script` | 只读使用；官方站点被 WAF 拦截，未取得正文 |
| curl | 抓取网页/PDF | 带浏览器 UA 请求 | 用于下载重庆市科技局 PDF、部分媒体页 |
| Python（标准库） | HTML 解析、文本清洗 | 提取标题、正文、链接 | 不执行第三方脚本 |
| pdftotext | PDF 文本提取 | 读取官方名单 PDF | 关键证据链工具 |

### 2.3 MCP 配置说明

- `browser-use` 为环境中**已连接**的 MCP，本轮仅调用只读能力，未修改其配置。
- 未新增 Web Search/Browser MCP，因为内置 WebSearch 已可用。
- 未修改全局配置，未写入任何密钥，未在源码、配置或日志中放置 API Key。
- 未安装来源不明的 MCP 服务。

## 三、调研过程

### 3.1 检索顺序

1. **学校与学院官方信息**：学校简介、学院简介、招生简章、硕士点简介。
2. **实验室名称核实**：先按用户提供的“脑机交互智能实验室”“具身智能实验室”检索，确认是否存在同名官方机构。
3. **研究方向与团队**：学院新闻、教师主页、学术会议简介。
4. **项目与成果**：教师主页项目栏、学院/学校新闻、竞赛新闻。
5. **设备与平台**：开放日新闻、平台介绍；无公开来源则不补充。
6. **交叉核验**：用政府名单、媒体全文、学术会议页面交叉验证。
7. **排除干扰**：逐一核对同名机构是否属于其他高校。

### 3.2 代表性检索词

- 重庆理工大学 脑机交互智能研究中心
- 重庆理工大学 脑机交互智能实验室
- 人形机器人具身智能感知与自主学习 重庆市重点实验室
- 重庆理工大学 具身智能实验室
- site:ai.cqut.edu.cn 具身智能开放平台
- 肖汉光 揭榜挂帅 具身智能机器人
- 重庆理工大学 两江人工智能学院 学院简介
- 2025 年拟认定重庆市重点实验室名单
- 重庆理工大学 第 28 届 中国机器人及人工智能大赛

### 3.3 WAF 限制与处理

重庆理工大学主站 `www.cqut.edu.cn`、学院站 `ai.cqut.edu.cn`、机械工程学院站 `jxgc.cqut.edu.cn` 均启用了 WAF。表现为：

- curl 返回 HTTP 412/202，正文为空或只有 JS 挑战脚本。
- 无头浏览器打开后页面空白，截图无可读内容。
- WebFetch 只能取得 JS 代码，无法取得正文。

处理方式：

1. **优先找官方 PDF 原件**：重庆市科技局名单 PDF 可直接下载，成为最高等级证据。
2. **使用搜索引擎索引摘录**：获取官方页面的标题、时间、关键段落。
3. **使用媒体转载全文交叉读取**：如华龙网对脑机中心成立仪式的全文报道。
4. **明确标注“间接核验”**：15 个 A 级官方页面均注明正文未直接打开。
5. **不把搜索摘要当最终证据**：关键结论尽量找第二个来源；找不到就降级或列为待确认。

### 3.4 干扰源排除

检索中出现多个同名或近名机构，已逐一排除，未采用其成果：

| 干扰源 | 所属单位 | 处理 |
|---|---|---|
| “具身智能实验室” | 重庆大学 | 排除，非重庆理工大学 |
| “具身智能与数智健康重点实验室” | 重庆师范大学 | 排除 |
| “HPC 团队 IROS 2026 成果” | 大连理工大学 | 排除，URL 核实为大连理工大学 |
| “脑机接口与类脑智能研究中心” | 北京理工大学 | 排除 |
| “控制与具身智能实验室” | 北京理工大学与重庆一中 | 排除，中学合作实验室 |

> 详细记录见 SOURCES.md 第六节 X01–X05。
