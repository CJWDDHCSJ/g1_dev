## 2. 协作模块

| 模块 | 路径 | 职责 |
|---|---|---|
| ASR Bridge | `~/unitree_ros2/example/g1_asr_bridge/src/asr_json_bridge.cpp` | 解析 Unitree ASR JSON → `/g1/asr_text` |
| TTS 节点 | `~/unitree_ros2/example/src/src/g1/audio_client/g1_tts_node.cpp` | `/g1/tts` → `TtsMaker` 播报 |
| Action Executor | `~/lidar_ws/src/g1_action_executor/` | 白名单动作执行与结果回传 |
